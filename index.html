mirror-system rclone client

This is a private OAuth client used by its owner only, to access their own Google Drive with rclone, an open-source file sync tool.

What it does

  • Uploads, downloads, lists and deletes files in the owner's own Google Drive.
  • Files are encrypted on the owner's computer before upload (rclone crypt).

Why it requests Google Drive access

The Google Drive scope is required so that rclone can read and write the owner's files for personal backup and storage. No other users' data is accessed.

Data handling

No data is sent to any server other than Google Drive. Nothing is collected, stored or shared by this app's developer.
